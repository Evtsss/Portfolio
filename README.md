# Портфолио аналитических проектов

В данном репозитории представлены проекты, посвящённые анализу данных и решению аналитических задач. Работы охватывают несколько направлений: анализ пользовательского поведения, исследование бизнес-показателей, обработку данных и проверку статистических гипотез.

В проектах используются SQL и Python для извлечения, подготовки и анализа данных, а также инструменты визуализации для представления полученных результатов.

## Проекты

### 1. Game Analytics — анализ игровых данных

**Цель проекта:** исследовать поведение игроков, особенности внутриигровых покупок и факторы, связанные с покупкой игровой валюты за реальные деньги.

В рамках проекта с использованием SQL проведён анализ платящей аудитории, внутриигровых транзакций и популярности игровых предметов. Отдельное внимание уделено сравнению активности игроков в зависимости от характеристик их персонажей.

[Перейти к проекту](./Game-Analytics/)

### 2. Yandex Afisha — анализ данных о продажах

**Цель проекта:** исследовать данные о заказах и мероприятиях, оценить показатели продаж и выявить особенности пользовательской активности.

В рамках проекта выполнена обработка и исследование данных с использованием SQL и Python, рассчитаны ключевые бизнес-показатели. Результаты анализа представлены в интерактивном дашборде, созданном в Yandex DataLens.

[Перейти к проекту](./Yandex-Afisha/)

### 3. Yandex Books — анализ результатов A/B-тестирования

**Цель проекта:** провести сравнительный анализ двух групп пользователей и проверить статистическую значимость различий между исследуемыми показателями.

В рамках проекта выполнена подготовка данных, проведён исследовательский анализ и проверка статистических гипотез с использованием Python. Для оценки результатов применены методы математической статистики.

[Перейти к проекту](./Yandex-Books/)

## Используемые инструменты

- **SQL:** PostgreSQL, JOIN, подзапросы, CTE, оконные и агрегатные функции.
- **Python:** Pandas, Matplotlib, исследовательский анализ и предобработка данных.
- **Статистика:** описательная статистика, проверка статистических гипотез.
- **Визуализация:** Yandex DataLens, построение графиков и аналитических дашбордов.
