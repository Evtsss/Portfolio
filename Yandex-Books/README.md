# Анализ данных Яндекс Книг и A/B-тестирование BitMotion Kit

## Цель проекта

Провести анализ данных сервиса Яндекс Книги, рассчитать основные продуктовые метрики и проверить гипотезу о различиях в активности пользователей из Москвы и Санкт-Петербурга. Дополнительно оценить результаты A/B-тестирования нового интерфейса интернет-магазина BitMotion Kit.

## Часть 1. Анализ данных Яндекс Книг

### SQL-анализ

С помощью SQL выполнена работа с данными сервиса Яндекс Книги за период с сентября по декабрь 2024 года.

Основные задачи:
- Определение топ-3 авторов по количеству уникальных пользователей за ноябрь.
- Определение топ-3 произведений по количеству уникальных пользователей с указанием жанра и автора.
- Расчёт Retention Rate для пользователей, активных 2 декабря.
- Расчёт LTV пользователей из Москвы и Санкт-Петербурга.
- Расчёт средней выручки за час прослушивания по месяцам.

### Проверка гипотезы в Python

На основе подготовленных SQL-запросом данных проведён анализ активности пользователей из Москвы и Санкт-Петербурга.

В ходе работы:
- Выполнена проверка и предобработка данных.
- Изучены размеры групп и основные статистические показатели.
- Проведена проверка статистической гипотезы с помощью одностороннего t-теста Уэлча.
- Проанализированы полученные результаты и сделаны выводы.

## Часть 2. A/B-тестирование BitMotion Kit

Проведён анализ A/B-тестирования нового упрощённого интерфейса интернет-магазина BitMotion Kit.

Цель эксперимента — проверить, увеличивает ли новый интерфейс конверсию зарегистрированных пользователей в покупателей как минимум на 3 процентных пункта в течение 7 дней после регистрации.

В ходе работы:
- Загружены и изучены данные об участниках эксперимента и пользовательских событиях.
- Проверена корректность распределения пользователей по группам.
- Рассчитаны показатели конверсии.
- Проведён статистический анализ результатов эксперимента.
- Сформулированы выводы о влиянии нового интерфейса на конверсию.

## Используемые инструменты

- **SQL (PostgreSQL)** — извлечение, объединение и агрегация данных, CTE, оконные функции.
- **Python** — анализ и предобработка данных.
- **Pandas** — обработка и исследование данных.
- **Matplotlib** — визуализация результатов.
- **SciPy** — статистические проверки гипотез.
- **Jupyter Notebook** — выполнение и оформление анализа.
