# SQL и Python проект — анализ данных сервиса Яндекс Афиша

**Цель проекта:** исследовать динамику продаж билетов и пользовательскую активность на сервисе Яндекс Афиша, выявить изменения в популярности мероприятий и проверить различия в поведении пользователей мобильных и стационарных устройств.

## Описание проекта

Яндекс Афиша — сервис, с помощью которого пользователи могут находить информацию о мероприятиях в разных городах и бронировать билеты. Сервис сотрудничает с организаторами мероприятий и билетными операторами.

В ноябре 2024 года продуктовая команда столкнулась с изменениями в продажах: спрос на одни мероприятия рос, на другие — снижался. Для выяснения причин требовалось изучить пользовательские предпочтения, определить наиболее популярные категории мероприятий, оценить вклад организаторов и площадок в продажи, а также сравнить активность пользователей разных типов устройств.

Проект состоит из двух частей.

## Часть 1. Анализ данных с помощью SQL и создание дашборда

На первом этапе выполнено знакомство с базой данных PostgreSQL, содержащей информацию о заказах, мероприятиях, площадках и регионах.

С помощью SQL проведён анализ структуры и качества данных, рассчитаны ключевые бизнес-показатели, исследована выручка и распределение заказов по основным категориям.

На основе полученных данных разработан интерактивный дашборд в **Yandex DataLens**, позволяющий отслеживать динамику ключевых показателей, анализировать популярность мероприятий и изучать структуру выручки в разрезе категорий событий и типов устройств.

## Часть 2. Исследовательский анализ данных и проверка гипотез

На втором этапе проведён исследовательский анализ данных с использованием Python. Исследование охватывает период с 1 июня по 31 октября 2024 года.

### Описание данных

Для анализа подготовлены три датасета.

**1. `final_tickets_orders_df.csv` — информация о заказах билетов**

Содержит данные о заказах, пользователях, мероприятиях, выручке и типах устройств.

- `order_id` — уникальный идентификатор заказа.
- `user_id` — уникальный идентификатор пользователя.
- `created_dt_msk` — дата создания заказа (московское время).
- `created_ts_msk` — дата и время создания заказа (московское время).
- `event_id` — идентификатор мероприятия.
- `cinema_circuit` — сеть кинотеатров.
- `age_limit` — возрастное ограничение мероприятия.
- `currency_code` — код валюты оплаты.
- `device_type_canonical` — тип устройства: мобильное или стационарное.
- `revenue` — выручка от заказа.
- `service_name` — название билетного оператора.
- `tickets_count` — количество купленных билетов.
- `total` — общая сумма заказа.
- `days_since_prev` — количество дней с предыдущей покупки пользователя.

**2. `final_tickets_events_df.csv` — информация о мероприятиях**

Содержит сведения о событиях, организаторах, городах, регионах и площадках проведения.

- `event_id` — уникальный идентификатор мероприятия.
- `event_name` — название мероприятия.
- `event_type_description` — описание типа мероприятия.
- `event_type_main` — основной тип мероприятия.
- `organizers` — организаторы мероприятия.
- `region_name` — название региона.
- `city_name` — название города.
- `venue_id` — уникальный идентификатор площадки.
- `venue_name` — название площадки.
- `venue_address` — адрес площадки.

**3. `final_tickets_tenge_df.csv` — данные о курсе тенге к российскому рублю**

Используется для пересчёта выручки из тенге в рубли.

- `nominal` — номинал (100 тенге).
- `data` — дата.
- `curs` — курс тенге к рублю.
- `cdx` — обозначение валюты (`kzt`).

### Этапы исследования

В ходе работы выполнены:
- загрузка и объединение данных;
- проверка пропусков, дубликатов и аномальных значений;
- анализ распределения выручки и количества билетов в заказах;
- приведение выручки к единой валюте — российским рублям;
- исследование сезонности и изменений пользовательских предпочтений;
- сравнение поведения пользователей мобильных и стационарных устройств;
- проверка продуктовых гипотез с применением статистических методов.

## Используемые инструменты

- **PostgreSQL, SQL:** исследование данных, JOIN, подзапросы, CTE, агрегатные и оконные функции.
- **Python:** Pandas, Matplotlib, исследовательский анализ и предобработка данных.
- **Jupyter Notebook:** проведение анализа и оформление результатов исследования.
- **Yandex DataLens:** создание интерактивного аналитического дашборда.
